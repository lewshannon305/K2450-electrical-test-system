# Keithley 2450 电学测试系统

基于 PyQt6 开发的 Keithley 2450 源表电学测试集成平台，支持 9 种测试模式的统一管理与参数配置。

## 1. 环境要求

- Python 3.10+
- PyQt6
- pyqtgraph
- pyvisa
- numpy

## 2. 安装依赖

### 方式一：使用 requirements.txt（推荐）

```bash
pip install -r requirements.txt
```

### 方式二：手动安装

```bash
pip install PyQt6 pyqtgraph pyvisa numpy markdown scipy matplotlib
```

## 3. 启动程序

```bash
python main.py
```

## 4. 系统功能总览

系统包含以下 9 个测试模块，可通过顶部导航栏切换：

| 序号 | 模块名称        | 功能描述                      |
| -- | ----------- | ------------------------- |
| 1  | 断裂结         | 断裂结电导测量，自动反馈步进            |
| 2  | 循环IV特性扫描    | 多轮次 I-V 曲线循环扫描            |
| 3  | 栅压特性扫描      | 固定偏压下栅压扫描（Isd-Vg / Ig-Vg） |
| 4  | 二维Mapping扫描 | 二维偏压 Mapping 扫描           |
| 5  | It特性扫描      | 电流-时间特性扫描，支持栅压联动          |
| 6  | 偏压开关测试      | 偏压方波开关测试，支持栅压监测           |
| 7  | 栅压开关测试      | 栅压方波开关测试                  |
| 8  | 任意偏压波形测试    | 自定义偏压波形序列                 |
| 9  | 任意栅压波形测试    | 自定义栅压波形序列                 |

## 5. 各模块详细说明

### 5.1 断裂结

**功能**：用于断裂结（Break Junction）电导测量，通过自动反馈步进算法实现量子电导平台的精确捕捉。

**工作原理**：

- 从起始电压开始，逐步施加偏压并测量电流
- 实时计算电导值（G = I/V），与目标电导值比较
- 根据电流变化比例自动调整步长，实现自适应反馈控制
- 每轮扫描结束后自动归零，进入下一轮循环

**核心参数**：

- **起始电压 (V0)**：扫描起始偏压值
- **最大电压 (V\_MAX)**：扫描电压上限
- **目标电导 (G\_AIM\_G0)**：目标电导值（以量子电导 G0 为单位）
- **电流限制 (CURRENT\_LIMIT)**：源表输出电流上限
- **步长 (step\_mV)**：初始电压步进量
- **步长增量 (speed\_mV)**：每轮步长增加量
- **最大步长 (max\_step\_mV)**：步长上限
- **电流变化比例阈值 (delta\_percent)**：触发电导反馈的电流变化百分比

**输出数据**：电压 (V)、电流 (A)、电导 (G0)

**实时显示**：I-V 曲线、电导-电压曲线

***

### 5.2 循环IV特性扫描

**功能**：支持多种模式的 I-V 特性曲线循环扫描，包括单向、双向、循环和脉冲模式。

**扫描模式**：

- **单向扫描 (Single)**：从起始电压扫描到终止电压
- **双向扫描 (Bidirectional)**：正向扫描后反向扫描
- **迟滞扫描 (Hysteresis)**：四段式扫描 0 → V_start → V_end → V_start → 0

**核心参数**：

- **起始电压 (V\_start)**：扫描起始值
- **终止电压 (V\_end)**：扫描终止值
- **步长 (V\_step)**：电压步进量
- **稳定时间 (Settle Time)**：每步电压施加后的等待时间
- **NPLC**：积分周期数（影响测量精度）
- **电流限制 (I\_limit)**：源表输出电流上限
- **循环次数 (Cycles)**：重复扫描轮数

**输出数据**：电压 (V)、电流 (A)、电导 (G0)、电阻 (Ω)

**实时显示**：I-V 曲线、电导-电压曲线

***

### 5.3 栅压特性扫描

**功能**：在固定偏压 (Vsd) 条件下，对栅压 (Vg) 进行四段式扫描，同时测量偏置电流 (Isd) 和栅电流 (Ig)。

**工作原理**：

- 使用两台 Keithley 源表：一台提供固定偏压，一台扫描栅压
- 四段式扫描：起始 → 第一拐点 → 第二拐点 → 返回第一拐点 → 终止
- 支持正向和反向扫描方向

**核心参数**：

- **偏压 Vsd**：固定偏置电压值
- **栅压起始/第一拐点/第二拐点/终止**：四段扫描的关键电压点
- **栅压步长 (Vg\_step)**：栅压扫描步进量
- **偏压表/栅压表地址**：两台源表的 GPIB 地址
- **偏压表/栅压表端口**：FRONT 或 REAR

**输出数据**：按扫描段分别保存为 4 个文件，包含 Vsd、Vg、Isd、Ig

**实时显示**：Isd-Vg 曲线、Ig-Vg 曲线（四段分别以不同颜色显示）

***

### 5.4 二维Mapping扫描

**功能**：在二维偏压空间（偏压 × 栅压）进行系统性扫描，绘制完整的电学特性 Mapping 图。

**工作原理**：

- 先进行预扫描（Ramp-up Phase），确定扫描范围
- 然后进行全扫描（Full Scan Phase），覆盖整个偏压-栅压空间
- 支持 Savitzky-Golay 滤波平滑数据（需安装 scipy）

**核心参数**：

- **偏压起始/终止/步长**：偏压扫描范围
- **栅压起始/终止/步长**：栅压扫描范围
- **偏压表/栅压表地址**：两台源表的 GPIB 地址
- **NPLC**：积分周期数
- **电流限制**：源表输出电流上限

**输出数据**：按扫描阶段分别保存，包含偏压、栅压、电流值

**实时显示**：预扫描阶段曲线、全扫描阶段曲线

***

### 5.5 It特性扫描

**功能**：电流-时间 (I-t) 特性扫描，支持固定偏压或阶梯偏压模式，可选栅压联动。

**工作模式**：

- **固定偏压模式**：在恒定偏压下记录电流随时间的变化
- **阶梯偏压模式**：偏压按设定步长逐步变化，记录每步的 I-t 曲线
- **栅压联动**：可启用第二台源表提供固定栅压
- **内部高速采集**：由 Keithley 2450 内部触发模型连续采样并写入仪表缓冲区，采集完成后批量传输，避免逐点 GPIB `READ?` 限速
- **块间自动调零**：每个连续数据块开始前自动调零一次，块内关闭自动调零以保持连续高速采样
- **可选工频谐波处理**：默认关闭。启用后拟合实际电网频率及其缓慢漂移，并扣除相应奇次谐波；该列只用于辅助观察，原始电流始终保留并作为正式数据

**核心参数**：

- **偏压 Vsd**：固定偏置电压或起始电压
- **NPLC**：单次积分时间；本机高速低噪推荐值为 0.05
- **点数/采样时间**：按指定点数或指定时长执行仪表内部连续采集
- **固定电流量程**：应选择能够覆盖最大预期电流的最小固定量程，避免自动换挡瞬态
- **自动调零模式**：`block_once` 为每块调零一次，`off` 为完全关闭

自动调零策略已按测量类型统一：循环 IV、栅压特性和二维 Mapping 等慢速逐点扫描保持 2450 函数级 Autozero 连续开启；断裂结、偏压/栅压开关、任意波形和 It 等时间敏感测量在连续采集前执行一次 `:SENS:AZER:ONCE`，随后关闭 Autozero，避免参考测量插入采集时间轴。
- **工频中心/搜索范围/最高奇次谐波**：仅在手动启用 `harmonic_fit` 时用于生成辅助处理列
- **阶梯步长/步数**（阶梯模式）：偏压阶梯参数
- **栅压 Vg**（可选）：固定栅压值

**输出数据**：

- 主数据文件同时包含仪表相对时间戳、偏压、原始电流 `BiasCurrentRaw(A)` 和工频处理后电流 `BiasCurrentFiltered(A)`
- `metadata` 子文件夹中的同名 `_meta.json` 保存实际采样率、工频起止频率与漂移率、各谐波幅度、处理前后 RMS 和是否中途终止
- 图中灰色曲线为原始数据，蓝色曲线为工频处理后数据

**速度说明**：2450 不具备真正的 digitize 功能。关闭 source readback 并使用固定量程后，本机实测 NPLC=0.01 约为 2.1 kSa/s，但会出现约 0.5 s 周期的噪声方差突发；NPLC=0.05 约为 0.79 kSa/s，周期突发基本消失，因此作为默认“高速低噪”工作点。它仍快于旧版逐点 `READ?` 在 NPLC=0.01 时约 0.38 kSa/s 的速度。程序会把周期突发诊断结果写入 `metadata` 子文件夹中的 `_meta.json`，检测到明显突发时在日志中提示，但不会插值或删除 Raw 数据。实际速度以 `_meta.json` 为准。为避免 GPIB 查询扰动采样，曲线在连续采集完成并读取缓冲后更新。

### 5.6 偏压开关测试

**功能**：偏压方波开关测试，在偏压 ON/OFF 状态间切换，记录瞬态响应，可选栅压监测。

**工作原理**：

- 在设定的偏压高电平和低电平之间周期性切换
- 记录每个开关周期内的电流瞬态响应
- 可选启用栅压表监测栅极电流

**核心参数**：

- **偏压高电平/低电平**：开关状态的电压值
- **高电平持续时间/低电平持续时间**：各状态保持时间
- **采样率**：数据采集频率
- **循环次数**：开关周期数
- **栅压监测**（可选）：启用栅压表记录 Ig

**输出数据**：时间 (s)、偏压 (V)、偏置电流 (A)、栅压 (V)、栅电流 (A)（如启用）

**实时显示**：偏压-时间曲线、偏置电流-时间曲线

***

### 5.7 栅压开关测试

**功能**：栅压方波开关测试，在栅压 ON/OFF 状态间切换，记录偏置电流的瞬态响应。

**工作原理**：

- 在设定的栅压高电平和低电平之间周期性切换
- 固定偏压，记录栅压切换时偏置电流的变化
- 适用于研究栅控器件的开关特性

**核心参数**：

- **栅压高电平/低电平**：开关状态的栅压值
- **高电平持续时间/低电平持续时间**：各状态保持时间
- **偏压 Vsd**：固定偏置电压
- **采样率**：数据采集频率
- **循环次数**：开关周期数

**输出数据**：时间 (s)、栅压 (V)、偏置电流 (A)、偏压 (V)

**实时显示**：栅压-时间曲线、偏置电流-时间曲线

***

### 5.8 任意偏压波形测试

**功能**：自定义偏压波形序列测试，支持多段波形定义，可选栅压联动。

**工作原理**：

- 用户可逐段定义波形的时长和电压值
- 按定义的序列依次输出偏压波形
- 可选启用栅压表提供固定栅压

**核心参数**：

- **波形定义**：每段波形的时长 (s) 和电压 (V)
- **偏压表/栅压表地址**：源表 GPIB 地址
- **偏压表端口**：FRONT 或 REAR
- **NPLC**：积分周期数
- **电流限制**：源表输出电流上限
- **栅压联动**（可选）：启用栅压表

**输出数据**：时间 (s)、偏压 (V)、偏置电流 (A)、栅压 (V)、栅电流 (A)（如启用）

**实时显示**：偏压-时间曲线、偏置电流-时间曲线、波形预览

***

### 5.9 任意栅压波形测试

**功能**：自定义栅压波形序列测试，支持多段波形定义，固定偏压下记录响应。

**工作原理**：

- 用户可逐段定义栅压波形的时长和电压值
- 按定义的序列依次输出栅压波形
- 固定偏压，记录偏置电流和栅电流

**核心参数**：

- **波形定义**：每段波形的时长 (s) 和栅压 (V)
- **偏压 Vsd**：固定偏置电压
- **偏压表/栅压表地址**：源表 GPIB 地址
- **NPLC**：积分周期数
- **电流限制**：源表输出电流上限

**输出数据**：时间 (s)、栅压 (V)、偏置电流 (A)、偏压 (V)、栅电流 (A)

**实时显示**：栅压-时间曲线、偏置电流-时间曲线、波形预览

## 6. 操作指南

### 6.1 硬件连接

运行前请确保 Keithley 2450 源表已通过 GPIB 与电脑连接。

### 6.2 初始化配置

进入任意测试模块后，先点击 **"扫描设备"** 按钮获取仪器地址，确认 GPIB 连接正常。

### 6.3 参数设置

每个模块包含以下参数区域：

- **仪器地址**：GPIB 地址与测试端口（FRONT/REAR）
- **预设参数**：启动前设置，测试过程中不可更改
- **控制参数**：支持实时修改（部分模块支持"应用修改"按钮）
- **文件保存路径**：设置输出文件名与保存目录

### 6.4 开始测试

点击 **"开始"** 按钮启动测量，实时数据将在左侧图表中显示，右侧状态面板实时更新。

### 6.5 停止测试

- **停止**：安全归零后停止
- **强制终止**：紧急情况下立即切断输出

### 6.6 配置管理

- **文件 → 保存配置**：将所有模块的测试参数导出为 JSON 文件
- **文件 → 加载配置**：从 JSON 文件恢复所有模块的测试参数

### 6.7 数据保存

测试数据自动保存至指定目录，格式为制表符分隔的文本文件，可用 Excel 或 Origin 打开。

### 6.8 测试结束后自动绘图

- **绘图 → 测试结束后自动绘图**：快速开启或关闭自动绘图
- **绘图 → 绘图设置**：打开三栏式绘图编辑器。左侧选择“通用”或 9 个测试模块；中间按“数据与分组、版式与导出、坐标轴与刻度、标题与文字、曲线与配色、图框/网格/图例、模块专用”分类设置；右侧用 PyQtGraph 显示该模块的独立单分子器件合成数据预览
- **绘图 → 绘制最近一次测试**：使用当前绘图配置重新绘制最近一次测试
- **绘图 → 查看最近绘图**：预览最近生成的 PNG 图片
- **绘图 → 打开最近绘图目录**：打开图片输出位置

九个测试程序仍分别保存各自的原始文本文件，并未把数据混入一个总文件。自动绘图只读取本次测试结果清单中实际成功保存的文件，不会混入同目录中的旧数据。正式图在后台生成，默认输出保留可编辑文字的 SVG、嵌入 TrueType 字体的 PDF 和 PNG；普通曲线默认 300 DPI，Mapping 默认 450 DPI。各模块可独立修改格式、DPI 和 Nature 单栏（89 mm）、1.5 栏（120 mm）、双栏（183 mm）尺寸。用户停止后若存在有效部分数据，可生成带 `PARTIAL` 标记的图片。

断裂结固定输出 Current（mA）和 Conductance（$G_0$）上下图；IV 支持单文件或同一栅压/循环分组、栅压叠加或小多图；Isd–Vg 只绘制 Isd，支持四线叠加、四幅无缝拼图和等间距偏移；Mapping 输出原始、平滑和微分电导三张图，并把 `full` 中每条 IV 单独输出至 `plots/mapping/full_iv`；It 输出左侧原始时序和右侧电流统计；其余四个时序测试固定为上方驱动电压、下方电流。

“应用”立即更新运行配置但不关闭窗口；“保存方案/加载方案”读写独立 JSON 绘图方案；“设为默认”供以后启动自动加载；“确认”应用并关闭。右侧是经过放大的屏幕预览，默认以 12–16 pt 的显示字号和约 3 px 曲线呈现；正式文件使用独立的物理参数，默认文字统一为 7 pt、曲线为 1 pt、刻度线为 0.8 pt。预览修改采用延迟合并刷新并隐藏重建过程，连续勾选或输入时不会为每次信号同步重绘；纯导出参数不会触发无意义的预览刷新。

所有正式图和预览图均关闭坐标轴自动科学计数倍率。电流会在绘图前自动换算为合适的 pA、nA、µA、mA 或 A，单位直接写入坐标轴标题；刻度和色条不会再显示 `×0.001`、`1e−9` 等额外换算标记。

## 8. 注意事项

1. **单任务限制**：系统同一时间仅允许一个模块运行测量，需停止当前测量后才能启动新模块
2. **紧急制动**：遇到异常情况请立即点击右下角 **"强制终止"** 按钮
3. **高频采样**：高频采样时请避免后台运行其他高负载程序
4. **参数备份**：建议定期使用"保存配置"功能备份测试参数
5. **GPIB连接**：确保 GPIB 驱动已正确安装，源表已开机并配置好地址
