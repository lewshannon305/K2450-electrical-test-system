# Keithley 2450 电学测试系统

面向 Keithley 2450 SourceMeter 的桌面电学测试平台。程序使用 PyQt6 构建统一界面，通过 PyVISA 控制一台或两台 2450，集成七种测量流程、实时显示、自动保存、结果元数据和论文级绘图。

> 本项目会直接控制源表输出。首次连接样品前，请先使用限流、低电压和空载条件验证接线、量程、端子与紧急停止流程。

## 下载与简易使用

普通 Windows 用户请前往 [Releases](https://github.com/lewshannon305/K2450-electrical-test-system/releases/latest) 下载 `K2450-Electrical-Test-System-Windows-x64.zip`。完整解压后双击 `K2450电学测试系统.exe` 即可启动，不需要安装 Python，也不需要创建虚拟环境。

请保留压缩包中的 `runtime` 和 `configs` 文件夹，并让它们与 EXE 位于同一目录。绿色 **Code → Download ZIP** 下载的是可查看、可编辑的 Python 源码，不包含 Windows 可执行程序。

## 主要功能

- 七种测量模块统一入口，支持单台或双台 Keithley 2450
- 自动扫描 VISA 资源，并校验仪器型号、端子、量程和关键参数
- 全局单任务保护，避免多个模块同时占用同一台仪器
- 正常停止、强制终止、退出拦截和测量结束自动归零
- 原始数据、运行状态与 `_meta.json` 元数据分开保存
- 支持完整结果及用户停止后的有效部分结果
- 自动生成 SVG、PDF、PNG，提供独立的绘图设置和预览界面
- 保存或加载全部模块参数、波形、开关状态与绘图方案
- 内置自动化测试，覆盖硬件安全、采集完整性、当前配置结构和绘图逻辑

## 运行环境

推荐环境：

- Windows 10/11
- Python 3.10 或更高版本
- Keithley 2450 SourceMeter
- NI-VISA、Keithley I/O Layer 或其他可被 PyVISA 识别的 VISA 后端
- GPIB、USB-TMC 或局域网 VISA 连接

程序会通过 `*IDN?` 检查仪器，当前仅接受 Keithley 2450。双表测试需要两台地址不同的 2450。

## 从源码运行

### 1. 获取代码

```powershell
git clone https://github.com/lewshannon305/K2450-electrical-test-system.git
cd K2450-electrical-test-system
```

### 2. 创建虚拟环境

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

### 3. 安装依赖

```powershell
pip install -r requirements.txt
```

主要 Python 依赖包括 PyQt6、PyQtGraph、PyVISA、NumPy、SciPy、Matplotlib 和 Markdown，具体最低版本以 `requirements.txt` 为准。

### 4. 检查 VISA 连接

源表开机并连接电脑后，可在 PowerShell 中先检查资源：

```powershell
python -c "import pyvisa; print(pyvisa.ResourceManager().list_resources())"
```

若返回空元组或报找不到 VISA library，请先安装或修复 VISA 后端，再启动程序。

### 5. 启动

```powershell
python main.py
```

## 第一次测量

1. 在首页点击“扫描设备”，统一选择偏压表、栅压表及 `FRONT` 或 `REAR` 端子。
2. 点击“检测连接”确认仪器状态；只连接一台偏压表时仍可使用单表测试模块。
3. 检查电压范围、电流限制、固定量程、NPLC、步长和稳定时间。
4. 在首页确认数据根目录，并填写各模块的根目录下保存路径。
5. 先用安全的小电压进行短测试，确认接线和数据列正确。
6. 点击“开始”执行测量；需要中止时优先使用“停止”。
7. 仅在异常或紧急情况下使用“强制终止”，随后确认仪器面板输出已经关闭。

## 七种测试模块

| 模块 | 仪器 | 用途与当前能力 |
| --- | --- | --- |
| 断裂结 | 1 台 | 自适应偏压步进和电导反馈，记录电压、电流及以 $G_0$ 表示的电导 |
| 循环 IV 特性扫描 | 1–2 台 | 单向、双向、回滞及自定义电压序列 IV；可选栅压表，并支持单值、升降序步进和自定义栅压序列 |
| 栅压特性扫描 | 2 台 | 固定源漏偏压下执行四段栅压扫描，同时记录 $I_{sd}$ 与 $I_g$ |
| 二维 Mapping 扫描 | 2 台 | 栅压与偏压二维扫描，包含预扫描、完整扫描、平滑和微分电导绘图 |
| It 特性扫描 | 1–2 台 | 偏压与可选栅压均支持单值、步进和自定义序列；双表启用时可形成 9 种组合，并支持高速触发和实时采样 |
| 任意偏压波形测试 | 1–2 台 | 在波形编辑器中定义多段偏压与持续时间，可选固定栅压，并支持两种采样模式 |
| 任意栅压波形测试 | 2 台 | 在固定偏压下执行多段自定义栅压波形，保存栅压、固定偏压和 $I_{sd}$，不保存 $I_g$ |

双电平或四段开关测试直接在任意波形编辑器中定义。例如依次加入测试电平、状态 1、测试电平、状态 2，并设置各段持续时间和循环次数，即可完成原有的开关序列；无需单独的开关测试模块。

### 三个时域模块的采样说明

It、任意偏压波形和任意栅压波形使用相同的采样设置，默认测量 NPLC 为 `0.05`，不另设采样间隔。两种模式都在当前 NPLC 下尽可能快地采样：

- “高速触发”使用 2450 内部触发模型和缓冲区，采集完成后批量传输数据并绘图，运行期间不逐点访问 VISA。
- “实时采样”由电脑连续读取 $I_{sd}$，按设定点数批量刷新曲线，适合需要观察测量过程的场景。
- 启用或使用栅压表时，实时模式约每 `1.0 s` 串行监测一次 $I_g$；$I_g$ 只显示最新状态，不保存，也不生成曲线。高速模式不监测 $I_g$。
- 任意栅压的高速模式由电脑切换栅压段，再由偏压表分段高速采集 $I_{sd}$。这是软件近似同步，程序会记录段间切换耗时，但不保证毫秒级栅压跳变同步。

It 的“总点数”和“测量时长”结束条件与采样模式相互独立。原始电流始终保留，工频谐波拟合默认关闭；启用后只增加辅助处理列及诊断信息。

Keithley 2450 不具备专用 digitize 功能。采样速度和噪声取决于 NPLC、固定量程、自动调零、总线与固件状态，应以每次测量的元数据为准。三个时域模块的元数据会记录采样模式、NPLC、实际平均采样率、时间间隔统计；任意栅压还会记录各段的切换耗时。

## 数据与元数据

各模块将数据保存为制表符分隔的文本文件，可用 Origin、Excel、Python 或 MATLAB 读取。程序使用唯一文件名和原子写入，已有文件不会被静默覆盖。

典型输出结构如下：

```text
选择的数据目录/
├── 测量结果.txt
├── metadata/
│   └── 测量结果_meta.json
└── plots/
    ├── 测量结果.svg
    ├── 测量结果.pdf
    └── 测量结果.png
```

元数据通常包含：

- 模块名称、保存时间和结果状态
- 完整、部分完成或错误状态，以及中止原因
- 仪器标识、端子和关键采集参数
- 栅压序列、实际采样率或滤波诊断等模块专用信息

若停止时已经获得有效数据，程序会尽力保存部分结果；对应图文件带有 `PARTIAL` 标记。发生安全告警或保存错误时，请同时查看界面日志和 `_meta.json`，不要只根据曲线判断测量是否完整。

## 自动绘图

“绘图”菜单提供以下操作：

- “测试结束后自动绘图”：控制测量结束后的后台绘图
- “绘图设置”：修改通用设置及七个模块的独立设置
- “绘制最近一次测试”：使用当前方案重新绘制最近结果
- “查看最近绘图”：预览最近生成的 PNG
- “打开最近绘图目录”：打开结果所在目录

默认正式输出包含可编辑文字的 SVG、嵌入字体的 PDF 和 PNG。普通模块默认 300 DPI，Mapping 默认 450 DPI。各模块可独立设置：

- Nature 单栏 89 mm、1.5 栏 120 mm 或双栏 183 mm 尺寸
- 字体、字号、线宽、颜色、图例、网格、刻度和坐标范围
- 线性或对数坐标、电流单位自动换算
- IV 文件/栅压/循环分组方式
- 栅压特性叠加或拼图方式
- Mapping 平滑参数、微分电导与逐条 IV 输出
- It 统计直方图、均值、中位数和标准差

自动绘图只读取本次测量成功记录的文件清单，不会把同目录中的旧数据混入新图。

## 配置文件

“文件 → 保存配置”会导出版本 3 JSON，包含：

- 七个模块的输入参数
- 复选框和单选按钮状态
- 数据目录
- 任意波形定义
- IV 栅压序列设置
- 当前绘图方案

“文件 → 加载配置”只支持当前版本 3 配置，不保留旧版本配置的迁移或兼容逻辑。

仓库提供三个实验配置样例：

- `configs/default.json`
- `configs/5T.json`
- `configs/9T.json`

这些文件在顶层 `instruments` 中统一保存 VISA 地址和端子，同时保留各模块实验参数，但不包含特定电脑的绝对数据目录。换电脑、换接线或换仪器地址后，必须先在首页重新扫描和确认，不能直接照搬。

绘图界面中的“设为默认”会在本机生成 `configs/plotting_default.json`，供以后启动时自动加载。

## 安全机制

- 同一时间只允许一个测量模块运行。
- 启动前验证仪器型号、地址冲突、端子、量程、限流、NPLC 和步进计划。
- 慢速扫描保持连续自动调零；时间敏感测量可在数据块前单次调零。
- 正常停止会结束采集并执行安全归零。
- 强制终止会请求紧急停止、快速归零并确认输出关闭。
- 测量仍在运行时关闭主窗口，程序会先请求停止并等待硬件清理。
- 归零、关闭输出或 VISA 清理失败会保留为告警，不会显示成成功完成。

软件保护不能替代硬件保护。请根据器件承受能力设置源表电流限制，并在高风险测试中使用外部限流、联锁或人工监护。

## 常见问题

### 扫描不到仪器

1. 确认 VISA 后端和 GPIB/USB/LAN 驱动已安装。
2. 用厂商工具确认仪器可以被发现。
3. 运行前面的 PyVISA 资源检查命令。
4. 检查地址是否与源表面板一致，以及是否被其他程序占用。

### 提示“仅支持 Keithley 2450”

程序会检查 `*IDN?` 返回值。请确认选中的资源确实是 2450，而不是总线上的其他仪器。

### FRONT/REAR 或量程校验失败

程序配置后会读取仪器实际状态。请检查面板设置、固件状态和接线，避免在未查明原因时绕过校验。

### 绘图没有生成

确认该模块绘图开关已启用、数据文件保存成功，并查看界面日志。部分结果只有在“绘制部分结果”启用时才会生成图。
